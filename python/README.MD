# CC Analayzer

## Prerequisites

Add Service Account's JSON file as `credentials.json` under `src` folder

## Install Dependencies

```
pip install -r requirements.txt
```

## Running the app

```
python3 src/main.py --sheet-name "NAME_OF_GOOGLE_SHEET" --billing-period "MONTH YEAR" --pdf-path "pdf/path" --pdf-password "password" 
```
